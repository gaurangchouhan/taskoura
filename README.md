# Taskoura

A web-based project management and collaboration platform that helps students manage software development projects using industry-standard Agile workflows — task tracking, Kanban boards, team collaboration, and AI-assisted planning powered by Grok.

## Tech Stack

- **Frontend:** React (Vite)
- **Backend:** Spring Boot (Java 21)
- **Database:** PostgreSQL
- **Authentication:** Spring Security + JWT
- **AI Integration:** Grok API (xAI)
- **Containerization:** Docker & Docker Compose
- **Deployment:** Render (backend) + Vercel (frontend)

## Folder Structure

taskoura/
├── backend/ # Spring Boot REST API
├── frontend/ # React (Vite) client
├── docs/ # SRS, ER diagram, API contract

└── README.md


## Getting Started

### Prerequisites
- Java 21
- Node.js 18+
- Docker & Docker Compose

### Run locally with Docker
```bash
docker compose up
```

### Run without Docker

**Backend:**
```bash
cd backend
mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
